# Third-party notices and source policy

This repository contains an unofficial GPL-3.0-or-later macOS wrapper around Jellyfin MPV Shim. The wrapper license is in [LICENSE.md](LICENSE.md). The source baseline and shader provenance are recorded in [README.md](README.md); retain upstream and shader notices and their individual applicable licenses.

## Shipped inputs, notices, and corresponding source

The release source ZIP is assembled from `git ls-files` content in this repository and the exact gitlink commits recursively (including their tracked files), not from the mutable build tree. Its `SOURCE-MANIFEST.json` records repository/submodule revisions and a content digest. It includes this repository's `scripts/`, `.python-version`, `uv.lock`, build configuration/locks, and the pinned Jellyfin MPV Shim and shader source trees. It intentionally excludes acquired runtime archives, extracted applications, generated helpers, and untracked build products. The GitHub asset names remain `Jellyfin-Player-<version>-Source.zip`, `Jellyfin-Player-<version>-Apple-Silicon.zip`, and `Jellyfin-Player-macOS-<version>-Apple-Silicon.dmg`.

| --- | --- |

## Release rule

`work/native_audit.py` and the bundle inventory generated by packaging describe the exact shipped app's binaries and files. They do not close licensing obligations unless every shipped component is matched to a version, license, notice, and corresponding source. In particular the prebuilt mpv asset's native transitive build inputs remain unproven as described above. Do not claim complete transitive notices/source or distribute on the basis of this record alone. A source ZIP is reproducible for a given Git revision and its pinned submodule gitlinks; prebuilt native binaries are separate inputs and are not made corresponding-source-complete merely by including wrapper source.
